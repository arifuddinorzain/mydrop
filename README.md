# mydrop

Aplikasi web minimalis untuk menghantar gambar, video, dan apa-apa jenis fail terus antara pelayar melalui kod QR (WebRTC P2P dengan geganti RAM sementara). Tiada fail disimpan di pelayan, dan semua data di penerima hilang automatik apabila halaman di-refresh.

## Cara guna

1. **Receive** — Papar kod QR untuk sesi penerimaan.
2. **Send** — Imbas kod QR (atau masukkan kod sesi).
3. **Select Files** — Pilih gambar, video, PDF, ZIP, atau apa-apa jenis fail.
4. **Transfer** — Fail dihantar terus dan boleh dimuat turun oleh penerima.

## Jalankan secara tempatan

```bash
npm install
npm start
```

## Ujian

```bash
npm test
```
